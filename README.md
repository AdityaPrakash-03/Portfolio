# Aditya Prakash — Portfolio

Product-builder portfolio. Next.js 16 (App Router) + TypeScript + Tailwind v4 + Framer Motion.

## The concept, in one line

**The monitor is the portfolio. The room is the personality.**

Every piece of real content (Work, Think, About, Signals, Toolbox) lives behind
the sticky top nav AND the monitor icon grid — a recruiter never has to touch
the illustrated desk to get everything they need. The physical desk objects
(notebook, certificate, bookshelf, phone, speaker) are optional shortcuts into
the *exact same* panels — one source of truth, two doors in. The speaker is
the only object that does NOT open a content panel — it's a pure easter egg
that plays an ambient track on click, never on autoplay.

## Quick start
